# SE-70-Rescue-Radar
RESCUE RADAR Community driven disaster identification and reporting application

This React Native Expo project is a mobile application aimed at facilitating the reporting of risky infrastructure such as trees, bridges, and other potential hazards in a specific location to the relevant authorities. The platform enables users to submit reports with details about the issue, and authorities can acknowledge receipt and take appropriate action.

Features

- Report Submission: Users can easily submit reports regarding risky trees, bridges, or other infrastructure by providing relevant details and location information.
- Location Services: The application utilizes location services to accurately pinpoint the location of the reported issue.
- Image Upload: Users can attach images to their reports to provide visual evidence of the reported problem.
- Real-time Notifications: Authorities receive real-time notifications when new reports are submitted and can acknowledge them accordingly.
- Acknowledgement System: Authorities can acknowledge receipt of the report and inform users when the reported issue has been addressed.

-  Installation

1. Ensure you have Node.js and npm installed on your machine.
2. Clone this repository to your local machine.
3. Navigate to the project directory in your terminal.
4. Run npm install to install dependencies.
5. Run expo start to start the development server.

 Dependencies

- React Native
- Expo
- React Navigation
- Axios (for making HTTP requests)
- React Native Maps (for displaying maps and location services)
- React Native Image Picker (for image upload functionality)
- Firebase (optional, for real-time notifications)

 Configuration

- Update Firebase configuration if you choose to use Firebase for real-time notifications.
- Make sure to obtain necessary API keys for location services if required.

 Usage

1. Launch the application on your mobile device or emulator.
2. Sign up or log in to your account.
3. Navigate to the report submission section.
4. Fill in the necessary details about the issue, including description, location, and attach relevant images.
5. Submit the report.
6. Authorities will receive a notification about the new report.
7. Authorities can review the report, acknowledge receipt, and take necessary action.
8. Users will receive updates on the status of their reported issues.
